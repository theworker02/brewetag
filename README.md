# brewetag

Brew numeric etag values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/brewetag/

## Install / run

```bash
git clone https://github.com/theworker02/brewetag.git
cd brewetag
node src/cli.js
node --test
```
